도메인 용어집

DICTIONARY_DATABASE

01

골드

Gold

게임 내에서 사용하는 기본 화폐. 아이템 구매 및 판매에 사용됨.

ex) 상점에서 물건을 살 때 사용하는 돈과 비슷함.

02

경험치

Experience Points (XP)

캐릭터 성장에 필요한 누적 점수. 전투 승리 등을 통해 획득.

ex) 활동을 하면 칭찬 스티커가 쌓이는 것과 비슷함.

03

레벨

Level

캐릭터의 성장 단계. 경험치가 누적되면 상승하며 능력치가 증가함.

ex) 학년이 올라가는 것과 비슷함.

04

MP

Magic Point

스킬 사용 시 소비되는 에너지 자원. 부족하면 기술 사용 불가.

ex) 배터리처럼 기술을 사용할 때 필요한 힘과 비슷함.

05

스테이지

Stage

게임 진행이 구분되는 단계 또는 구간. 난이도와 적이 다름.

ex) 한 판의 미션이나 코스와 비슷함.

06

몬스터

Boss / Monster

플레이어가 전투를 통해 상대하는 적 캐릭터. 보스는 마지막 강적.

ex) 시험의 마지막 어려운 문제와 비슷함.

07

장비

Equipment

캐릭터 능력치(공격력, 방어력 등)를 향상시키기 위해 착용하는 아이템.

ex) 운동 시 착용하는 보호장비와 비슷함.

08

소비템

Consumable Item

사용 시 즉시 효과가 발생하며 한 번 사용하면 소멸되는 아이템.

ex) 먹으면 사라지는 간식과 비슷함.

09

스킬Lv

Skill Level

개별 기술의 강화 단계. 상승 시 기술의 위력이나 효과가 증가함.

ex) 연습할수록 실력이 좋아지는 것과 비슷함.
