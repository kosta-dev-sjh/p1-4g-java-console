1) 스키마 네이밍 오류

DATE: 2026-03-12 | AUTHOR: 이진주

[PROBLEM]

네이밍이 character인 테이블을 생성하려니 생성 불가

2) git conflict 오류

DATE: 2026-03-19 | AUTHOR: 홍준화

[PROBLEM]

git pull / merge 시, 공백(whitespace) 충돌 다수 발생

[CAUSE]

.gitattributes가 기존에 커밋된 파일들에는
제대로 반영되지 않음

[SOLUTION]

1) 전체 파일을 .gitattributes 기준으로 정규화

2) 현재 추적 중인 모든 파일을 다시 인덱스에 등록

3) 설정이 기존 파일에도 적용되도록 normalization

[RESULT]

모든 파일 공백/개행 통일 완료.
git pull/merge 시 충돌 해소 및 코드 일관성 향상

3) db.properties 정보 유출

DATE: 2026-03-12 | AUTHOR: 홍준화

[PROBLEM]

git merge 시 db.properties 파일이 같이 올라감

[CAUSE]

파일이 이미 repo에 commit 되어 있었기 때문에
.gitignore가 tracking 된 파일을 막지 못함

[SOLUTION]

1) git rm --cached -r src/**/db.properties 실행

2) git commit -> push -> merge 재진행

3) 보안을 위해 AWS RDS의 Master password 수정

[RESULT]

보안 파일 제외 처리 성공 및 정보 유출 완벽 차단
